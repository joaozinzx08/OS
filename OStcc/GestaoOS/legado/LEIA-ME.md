# Referência do projeto anterior

Esta pasta preserva o backend, frontend, dados JSON e anexos recebidos, para consulta e importação. Não faz parte da aplicação executada pelos comandos da raiz. Não execute este backend antigo para usar a versão nova.

O histórico `.git`, a pasta `node_modules` e o `.env` antigo foram omitidos do pacote reformulado. Os documentos anteriores estão em `docs/documentos-originais`.

Use os arquivos locais originais como backup adicional. Não publique dados pessoais, hashes de senha ou anexos desta pasta em um repositório público.
